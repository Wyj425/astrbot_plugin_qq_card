# QQ卡片签名

适用 AstrBot **4.29.3 及以上**，Python 3.12；当前实际验证版本为 AstrBot 4.29.3。其他版本需自行验证兼容性。

- 统一保存咸鱼 API 开放平台 qq-shareArk Token，生成经校验的 QQ 图文卡片。
- 保持签名返回的 JSON 原文不变，校验目标链接、标题、封面和签名。
- 提供实验性的 QQ音乐/网易云原生音乐卡片接口；失败时由点歌退回签名链接卡片。
- 不提供 B站小程序大卡；默认图文卡可能显示“其他来源”，这是签名服务/QQ的呈现限制。
- 此插件只生成卡片，不自行向群或好友发送；没有自动群发和模型工具。

## 安装

1. 本插件仓库：[Wyj425/astrbot_plugin_qq_card](https://github.com/Wyj425/astrbot_plugin_qq_card)，由 `Wyj425` 维护。
2. 在 AstrBot → 插件 → 从链接安装，填写 `https://github.com/Wyj425/astrbot_plugin_qq_card`；也可导入只包含本目录的 ZIP。不要上传整个工作目录。
3. AstrBot 按 `requirements.txt` 安装 Python 依赖。启用插件后，在插件配置页设置。
4. 可独立安装，不依赖社区精选、点歌或其他三个能力插件。

## 使用与登录

在 [咸鱼 API 开放平台](https://apii.xianyuw.cn) 注册并获取个人 Token，填入本插件的 `ark_signing_token`。社区精选和点歌不再重复填写。第三方服务会接收卡片标题、简介、封面URL、目标URL和签名Token；不会接收聊天记录或平台登录Cookie。费用、可用性和配额以服务方当前规则为准。

返回消息编号只表示 OneBot 接口受理，并不证明手机端显示成功。实际效果仍需在 QQ 客户端确认。不得在签名后修改标题、底部来源或封面，否则可能无法送达。

## 数据、费用与卸载

插件数据保存在 AstrBot 的 `data/plugin_data/astrbot_plugin_qq_card/`，配置位于 `data/config/astrbot_plugin_qq_card_config.json`。扫码凭据不返回到模型、聊天或普通日志。平台搜索/详情缓存按公开内容共享，会话最近链接按完整会话标识隔离；重启清空内存缓存，候选库与发送记录等业务数据库仍持久化。

平台读取与签名本身不调用语言模型。正文、评论和配图进入聊天模型时会增加输入用量；社区评分、兴趣分析、人设短评及知识提取仍按各插件设置计费。没有无限抓取或无限评论翻页。

卸载插件不会自动清除平台账户的远程登录，也不应直接删除需要保留的数据。停用平台插件后，消费者会报告依赖不可用或跳过该平台。需要重新安装时恢复本插件目录及配置；平台失效需重新扫码。
