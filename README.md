# QQ卡片签名

**让社区分享和点歌结果以带标题、封面、可点击跳转的 QQ 卡片展示。**

这是供「社区精选分享」「大肥鱼点歌」调用的配套插件。安装后，在这里配置一次卡片签名 Token，配套插件即可复用。实际发送由调用它的插件完成。

<img src="logo.png" width="120" alt="QQ卡片签名插件图标">

## 能做什么

- 为图文分享生成带标题、简介、封面和目标链接的 QQ 卡片。
- 集中管理签名 Token，方便配套插件使用。
- 提供实验性的 QQ音乐、网易云原生音乐卡片生成能力。
- 检查签名结果中的目标链接及必要字段，保持签名后的卡片内容完整。

适用于 **AstrBot 4.29.3 及以上、Python 3.12，QQ / OneBot 接入**。当前已验证 AstrBot 4.29.3。

## 安装与配置

1. 在 **AstrBot → 插件市场** 搜索「QQ卡片签名」，点击安装。
2. 打开 [咸鱼 API 开放平台](https://apii.xianyuw.cn)，注册并登录。
3. 在个人中心获取自己的 **Token**。
4. 打开 **AstrBot → 插件 → QQ卡片签名 → 配置**。
5. 开启 `enabled`，将 Token 填入 `ark_signing_token`，保存配置。
6. 在需要使用卡片的插件中选择卡片模式，再进行实际发送测试。

所需 Python 依赖由 AstrBot 安装；卡片签名使用第三方在线服务，无需自行部署签名服务器。

## 两种配置方式

### 方式一：让 Agent 帮你检查配置（推荐）

先自己完成平台注册并取得 Token，然后把下面的提示词发给 Agent：

```text
我已安装 AstrBot 的「QQ卡片签名」（astrbot_plugin_qq_card）。
请阅读：
https://github.com/Wyj425/astrbot_plugin_qq_card

请检查插件是否正常加载，指导我在插件配置中填写自己的
ark_signing_token，并确认 enabled 已开启。
Token 由我在后台填写，不要在聊天中索要或输出 Token。

根据我已安装的社区精选分享或点歌插件，检查卡片调用所需的配置。
需要发消息验证时，先让我指定测试会话，再测试标题、封面和点击跳转。
最后告诉我问题所在和配置结果。
```

### 方式二：手动配置

按上面的六个步骤填写配置即可。卡片 Token 填写在本插件的配置页中。测试方式：

- 使用「大肥鱼点歌」时，先将其 `card_mode` 设为「签名链接卡片」，私聊发送「点歌 晴天」。
- 使用「社区精选分享」时，完成订阅配置，等待一次计划推送，在 QQ 中检查卡片展示和跳转。

本插件没有单独的聊天指令，发一句「生成卡片」不会直接触发它。

## 卡片会是什么样

图文卡片通常包含 **标题、简介、封面和可点击链接**。底部可能显示「其他来源」，具体样式由签名服务和 QQ 决定。

原生音乐卡片当前属于实验性能力。是否显示、能否在 QQ 内直接播放，会受平台与 QQ 客户端影响；点歌插件可以选择签名链接卡片作为稳定起步方式。

## 常见问题

**已经填 Token，还是没有卡片？**

确认插件已启用，Token 有效且签名服务可用；再检查点歌或社区分享插件的模式和依赖状态。错误信息可在 AstrBot 日志中查看。

**后台返回了消息编号，手机却收不到？**

消息编号表示发送接口已受理，请以 QQ 客户端实际收到的内容为准。修改已经签名的标题、封面或底部来源，可能使卡片无法送达。

**为什么底部显示“其他来源”？**

这是当前图文卡片通道的展示限制。本插件暂时没有自定义底部来源的设置。

## 数据与费用

配置保存在 `data/config/astrbot_plugin_qq_card_config.json`。

生成卡片本身不调用聊天模型。图文签名请求会将卡片标题、简介、封面链接、目标链接和 Token 发给咸鱼 API；原生音乐卡片请求会将歌曲平台和歌曲 ID 发给对应的第三方生成服务。服务费用、配额和可用性以服务方当前规则为准。

备份配置时请保管好 Token；卸载后若要停止使用该 Token，可在服务平台管理或撤销它。
